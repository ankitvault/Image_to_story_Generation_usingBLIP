# Image_to_story_Generation_usingBLIP
A Flask web application that generates cohesive narrative stories from sequences of images using a finely-tuned BLIP model for image captioning and Google's FLAN-T5-large model for storytelling.

### Setup
1. Clone the repository.
2. Ensure you have the required dependencies (refer to requirements.txt).
3. Place your fine-tuned BLIP model in the `k7owntrained` folder.
4. Run `python app.py` to start the server.
